# Аудио

🌐 **Русский** · [English](../../ef2dg_Docs_en/03_Modules/Audio.md)

`AudioEngine` реализует `IAudioService` поверх OpenAL. При запуске создаётся пул из 16 источников эффектов и отдельный циклический источник музыки. `AudioLocator` предоставляет сервис компонентам и имеет безопасную `NullAudioService`-заглушку.

`PlaySFX` помещает команду в очередь; `ProcessFrame` ограничивает одинаковые звуки двумя за кадр, выбирает свободный источник и обновляет позицию слушателя по камере. Поддерживается декодирование WAV. `PlayMusic`, `PauseAll`, `ResumeAll` и `StopAll` управляют музыкой и эффектами.

`AudioSourceComponent` хранит громкость, путь по умолчанию, флаги `PlayOnStart`/`IsMusic` и словарь `SoundClips`. `PlayOneShot(key)` используется событиями кадров [SpriteComponent](SpriteComponent.md).
