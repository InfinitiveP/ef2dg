# Каталог компонентов

🌐 **Русский** · [English](../../ef2dg_Docs_en/03_Modules/Component%20Catalog.md)

Ниже перечислены компоненты, найденные в текущих исходниках, их зависимости и особенности настройки.

## SpriteComponent

Рисует sprite sheet и управляет state machine анимации. Требует корректные пути текстур. Для звуков кадров нужен `AudioSourceComponent` на том же объекте. Словари сохраняются через `AnimationsJson` и `ParametersJson`.

## PhysicsBody

Обрабатывает скорость, гравитацию, тайловые столкновения, склоны и триггеры. Нужны `Owner.ParentScene` и `Map`. Для платформера используйте `GravityScale > 0`, для top-down — `0`. Твёрдые `BoxCollider` не останавливают тело.

## BoxCollider

Хранит AABB-зону. При `IsTrigger = true` обнаруживается чужим `PhysicsBody` и генерирует callbacks. При `false` сейчас служит главным образом для визуализации и будущего расширения физики.

## CameraFollowComponent

В `Draw` один раз запоминает переданную камеру в статическом поле, затем в `FixedUpdate` плавно ведёт её к `Owner.Position + Offset`. До первого `Draw` компонент не двигает камеру. Статическая ссылка общая для всех экземпляров.

## LightComponent

Источник света: `Color`, `Intensity`, `Radius`, `Offset`, `Falloff`, ядро свечения `Glow`/`GlowSize`, мерцание `FlickerAmount`/`FlickerSpeed`, пульсация `PulseAmount`/`PulseSpeed`, флаг `Enabled`. Сам `Draw` пуст; источники собирает `LightingRenderer`. Свет виден, только если освещение включено у сцены в окне Lighting. В Inspector у компонента собственный блок с пресетами. Подробнее — [Освещение](../05_Guides/Освещение.md).

## AudioSourceComponent

Запускает музыку или позиционный SFX, хранит словарь ключей клипов. `PlayOnStart` срабатывает однажды на экземпляр компонента; для повторного запуска нужен `ResetPlayState`. Гарантированно поддерживается PCM WAV.

## ParticleEmitterComponent

Создаёт пул частиц с параметрами скорости, области рождения, времени жизни, размера, цвета, гравитации и вращения. Цвета `StartColor`/`EndColor` имеют тип `Vector4D` и сохраняются в `VectorValues`. В исходниках присутствует неиспользуемое поле `_texture`; фактическая текстура получается по `TexturePath` через ресурсы.

## ButtonComponent

Описывает кнопку: `Label`, экранный `Size`, `TargetSceneName`, `IsOverlay`, `IsHovered`. `SceneViewWindow` рисует её как ImGui-кнопку либо как текстуру `SpriteComponent`. Переход по JSON или имени класса выполняется только при клике в Play Mode. `IsHovered` обновляется редактором и сохраняется как обычное публичное свойство, хотя является временным UI-состоянием.

## PlayerController

Требует `SpriteComponent` и `PhysicsBody`. Использует действия `Left`, `Right`, `Up`, `Down`, `Jump`, `Attack`. При `GravityScale > 0` работает как платформер, при `0` — top-down. Атака удаляет любую чужую сущность с `PhysicsBody`, попавшую в AABB удара; системы здоровья или команд пока нет.

## EnemyAIComponent

Требует `SpriteComponent` и `PhysicsBody`, ищет первую сущность с `PlayerController`. Движется только по X, преследует в `SightRadius` и запускает анимацию атаки в `AttackRadius`. Фактический урон игроку не реализован.

## SmartStoneComponent

Ищет игрока и движется от него по X внутри `TriggerRadius`. Работает без обязательных компонентов, но движение требует `PhysicsBody`, а анимация — `SpriteComponent`.

## TeleportTriggerComponent

При `OnTriggerEnter` ищет у вошедшего объекта `PlayerController`. Если `TargetSceneName` пуст, выполняет перенос на `TargetLocation`; иначе загружает указанную JSON-сцену или класс сцены. Оба режима используют `Transition`. Для вызова нужен объект-зона с `BoxCollider.IsTrigger = true` и игрок с `PhysicsBody`. Подробнее: [Переходы между локациями](../05_Guides/Переходы%20между%20локациями.md).
