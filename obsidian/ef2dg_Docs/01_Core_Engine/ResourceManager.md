# ResourceManager

Менеджер владеет OpenGL-текстурами и кэширует их по строковому пути. `GetTexture(path)` возвращает уже загруженный объект либо создаёт новый. При отсутствии файла возвращается и кэшируется магента-чёрная текстура-заглушка `MissingTexture`.

Также доступна однопиксельная `WhiteTexture`, используемая как запасной ресурс для света. Все загруженные текстуры и служебные текстуры освобождаются в `Dispose()` при закрытии движка.

Пути относительны к рабочему каталогу процесса; запускайте проект из `ef2dg`.
