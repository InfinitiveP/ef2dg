# Camera

`Camera` хранит `Position`, `Front`, `Up`, `Zoom` и размер окна. Она создаёт матрицу вида через `CreateLookAt` и ортографическую матрицу проекции.

- `Zoom = 1` задаёт высоту мира в две условные единицы; увеличение `Zoom` показывает большую область.
- `ViewWidth` и `ViewHeight` используются для отсечения невидимых сущностей и тайлов.
- При изменении окна `Engine.OnResize` вызывает `UpdateSize`.

В Edit Mode камера перемещается клавишами `W`, `A`, `S`, `D`; масштаб в `Scene View` изменяется колесом мыши. В Play Mode её может обновлять `CameraFollowComponent`.
