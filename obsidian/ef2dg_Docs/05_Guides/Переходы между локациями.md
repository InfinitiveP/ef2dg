# Переходы между локациями

🌐 **Русский** · [English](../../ef2dg_Docs_en/05_Guides/Scene%20Transitions.md)

Система реализует единый переход для смены сцен, стековых оверлеев и произвольных действий. Во время визуального эффекта обновление сцен, физика, управление камерой редактора и обработка игрового аудио приостанавливаются. Само действие выполняется в середине эффекта.

## TransitionSettings

`TransitionSettings` содержит:

- `Kind` — `Instant`, `Fade`, `CrossFade`, `SlideLeft`, `SlideRight`, `SlideUp`, `SlideDown`;
- `Duration` — полная длительность эффекта в секундах, по умолчанию `0.5`;
- `Color` — цвет промежуточного фона и затемнения, по умолчанию чёрный.

`Instant` сохраняет прежнее поведение движка. Настройки сериализуются в `ComponentData.TransitionValues`, включая RGBA-цвет.

## Фазы

1. Движок заканчивает текущий кадр и копирует его в отдельный framebuffer.
2. Первая половина эффекта скрывает старый кадр.
3. В средней точке выполняется действие: телепорт, загрузка, `ChangeScene`, `PushScene` или `PopScene`.
4. Вторая половина показывает новый кадр.

Повторный запрос во время активного перехода возвращает `false` и игнорируется. Если загрузка сцены завершается ошибкой, движок пишет сообщение `[Transition ERROR]` и показывает исходную сцену обратно.

## Настройка ButtonComponent

У компонента раскройте группу `Transition` в `Inspector`, выберите `Effect`, `Duration` и `Color`. `TargetSceneName` может содержать имя JSON-файла с расширением или без него, имя открытой сцены либо имя класса-наследника `Scene`. `IsOverlay` выбирает между заменой стека и `PushScene`.

Загрузка JSON откладывается до середины эффекта, поэтому пауза чтения и десериализации скрывается переходом.

## Настройка TeleportTriggerComponent

- Пустой `TargetSceneName` — перенос игрока на `TargetLocation` внутри текущей сцены.
- Непустой `TargetSceneName` — загрузка JSON-файла или сцены по имени.
- `Transition.Kind = Instant` — действие без визуального эффекта.

Зона должна иметь `BoxCollider.IsTrigger = true`; входящий игрок — `PhysicsBody` и `PlayerController`.

## Использование из кода

Смена готовой сцены:

```csharp
Engine.Instance.ChangeScene(targetScene, new TransitionSettings
{
    Kind = TransitionKind.Fade,
    Duration = 0.6f,
    Color = new Vector4D<float>(0f, 0f, 0f, 1f)
});
```

Загрузка по имени или JSON:

```csharp
Engine.Instance.RequestSceneTransition(
    "level_2.json",
    isOverlay: false,
    settings: Transition);
```

Произвольное действие под эффектом:

```csharp
Engine.Instance.RunTransition(
    () => Owner.Position = TargetLocation,
    Transition);
```

Также доступны перегрузки `PushScene(scene, settings)` и `PopScene(settings)`. Старые методы без настроек остаются мгновенными.

## Визуальные особенности

- `Fade` закрывает старый кадр цветом и открывает новый.
- `CrossFade` сначала приглушает старый кадр к цвету, затем смешивает сохранённый кадр с новым.
- `Slide*` выдвигает старый кадр в указанную сторону и вводит новый с противоположного края.
- Эффект компонуется после игрового рендера и освещения, но до показа framebuffer в `Scene View`.
