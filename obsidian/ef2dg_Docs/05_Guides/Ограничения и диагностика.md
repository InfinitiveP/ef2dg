# Ограничения и диагностика

🌐 **Русский** · [English](../../ef2dg_Docs_en/05_Guides/Limitations%20and%20Diagnostics.md)

`dotnet build` успешно выполняется с .NET SDK 10.0.101: ошибок нет. Компилятор выдаёт предупреждение `CS0169`: поле `_texture` в `ParticleEmitterComponent` объявлено, но не используется.

Графический запуск зависит от OpenGL-драйвера, оконной системы и аудиоустройства. При проблемах проверьте запуск из каталога проекта, существование файлов шейдеров и путей из `assets/`, а также сообщения в окне `Console`.

`bin/` и `obj/` — производные артефакты сборки. Их не следует считать исходниками, редактировать или добавлять в репозиторий.

## Известные функциональные ограничения

- Play Mode не создаёт копию сцены и не откатывает изменения после остановки.
- Undo/Redo реализованы только для редактирования тайлов.
- `Vector4D<float>` сохраняется сериализатором массивом из четырёх чисел в `VectorValues` (с 2026-11-03). Цвет внутри `TransitionSettings` по-прежнему хранится отдельным `TransitionValues`.
- `File → Save` (`Ctrl+S`) сохраняет живую сцену и в Play Mode: заспавненные мобы, урон и подобранные предметы попадут в JSON. Сохраняйте уровень только в Edit Mode после повторной загрузки файла.
- В окнах выбора аудио видны WAV, OGG и MP3, однако `AudioEngine` декодирует только PCM WAV с заголовком RIFF/WAVE.
- `BoxCollider` с `IsTrigger = false` визуализируется, но не участвует в разрешении столкновений `PhysicsBody`; твёрдая физика идёт через [Tilemap](../03_Modules/Tilemap.md).
- Новая пустая `GameScene`, созданная кнопкой `+`, может не получить карту, потому что редактор выставляет `IsLoadedFromFile = true`, а `GameScene.Load` завершает работу раньше создания `Tilemap`. Для надёжной работы загружайте подготовленный JSON-уровень.
- Список `File → Open...` показывает все JSON-файлы рабочего каталога, кроме служебных (`bindings.json`, `level_backup.json`, `project_config.json`, `lighting_presets.json`, `editor_layout.json`).
