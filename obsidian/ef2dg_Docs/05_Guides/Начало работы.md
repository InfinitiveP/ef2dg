# Начало работы

## Требования

Нужны .NET SDK 10, драйвер с OpenGL 3.3 и, для аудио, доступное устройство OpenAL. Проект использует Silk.NET, ImGui.NET, Newtonsoft.Json и StbImageSharp.

## Сборка и запуск

Откройте терминал в каталоге `ef2dg` и выполните:

```powershell
dotnet build --no-restore
dotnet run
```

Рабочий каталог важен: `project_config.json`, `bindings.json`, шейдеры, JSON-уровни и `assets/` читаются относительными путями.

## Структура

`Core/` — рантайм; `Framework/` — базовые сущности, карта и сериализация; `Rendering/` — OpenGL; `Components/` — переиспользуемая логика; `Game/` — игровая логика; `Editor/` — ImGui-редактор; `assets/` — ресурсы.
