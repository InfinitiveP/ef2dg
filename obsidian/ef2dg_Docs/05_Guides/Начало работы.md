# Начало работы

🌐 **Русский** · [English](../../ef2dg_Docs_en/05_Guides/Getting%20Started.md)

## Требования

Нужны .NET SDK 10, драйвер с OpenGL 3.3 и, для аудио, доступное устройство OpenAL. Проект использует Silk.NET, ImGui.NET, Newtonsoft.Json и StbImageSharp.

## Сборка и запуск

Откройте терминал в каталоге проекта (`ef2dg`) и выполните:

```powershell
dotnet build
dotnet run
```

Рабочий каталог важен: `project_config.json`, `bindings.json`, шейдеры, JSON-уровни и `assets/` читаются относительными путями.

## Структура

`Core/` — рантайм; `Framework/` — базовые сущности, карта, сериализация и освещение сцены; `Rendering/` — OpenGL; `Components/` — переиспользуемая логика; `Game/` — пример игровой логики; `Editor/` — ImGui-редактор; `Shaders/` — шейдеры освещения и постобработки; `assets/` — ресурсы.
